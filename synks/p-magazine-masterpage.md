Learn how to create style templates for your InDesign project using parent pages.

## Prequisites

Before you get started with the parent page, be sure to:
- Assemble the text, images, and other content needed for your project.
- Create hand-drawn sketches to serve as a visual reference for the layout of each page.
- Create a new project in InDesign.
- Configure settings for your desired page dimensions and number of pages.
- Create margins by clicking on the ruler and dragging to the edges of the page. Margins should be between 0.25 and 0.5 inches.

## 1. Create a New Parent Page

<!-- We'll get into some copyediting later, but you should avoid burying helpful info within parantheses. Instead, simply use a colon. "...: *Windows* > *Pages*." -->
1. In InDesign, open the pages panel: **Windows** > **Pages**
2. In the upper right corner of the panel, click the small icon containing 4 horizontal bars. <!-- add image -->
3. Select **New Parent...** from the dropdown menu.
4. Add a prefix letter in the New Parent dialog box. The first parent should be "A", the second "B", etc.
5. Add a name for the parent page in the dialog box that appears.
6. Once you verified the desired result with the preview, click **OK**
>Note: When you have done this successfully, you will see your newly named parent page appear in the pages menu on the right side of the page.

## 2. Add Column Guides

1. In the **Pages** panel, double-click the newly created parent page to open it in your workspace.
2. Select the **Layout** menu from the main toolbar and select **Margins and Columns**.
3. In the dialog box, type the desired number of columns
4. Set the spacing between the columns, known as "gutters".
>Note: 0.25 inches is a good place to start for gutters, but if you are creating four or more columns, you may want to go smaller.
5. Check the box marked "Preview" so that you can view your guides on the page as your create them.

## 3. Apply the Parent Page
1. Go back to the **Pages** panel and select the parent page at the top of the panel. It will be indicated by a letter in the top corner of the page. Your first parent page will be marked with an "A".
2. Click on the parent page thumbnail and drag it down to the thumbnail for the desired document page.
3. Apply the parent page by releasing the mouse button when a black rectangle appears on the border of the page.
