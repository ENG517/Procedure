Learn how to create style templates for your InDesign project using parent pages.

## Prequisites

Before creating the parent page, complete the following:
- Assemble the text, images, and other content needed for your project.
- Create a new InDesign document.
- Configure the document settings for your desired page size and number of pages.

## Create a New Parent Page

<!-- We'll get into some copyediting later, but you should avoid burying helpful info within parantheses. Instead, simply use a colon. "...: *Windows* > *Pages*." -->
1. Open the **Pages** panel from the menu bar: **Windows** > **Pages**
2. In the upper-right corner of the panel, click the panel menu icon with 4 horizontal lines.   <!-- add image -->
3. Select **New Parent...** from the menu.
4. In the **New Parent** dialog box, enter a prefix letter. Use "A" for the first parent, "B" for the second, and so on.
5. Enter a name for the parent page.
6. After verifying the page size and orientation, click **OK**
>Note: When the parent page is created successfully, it will appear in the **Pages** panel with the specified name and prefix.

## Add Column Guides

1. In the **Pages** panel, double-click the parent page thumbnail to open it in your workspace.
2. Open the **Margins and Columns** dialog box: **Layout** > **Margins and Columns**.
3. Set the desired margins and number of columns.
>Tip: Margins should be at least .5 inches on each side. 
4. Set the gutter width to adjust space between the columns.
>Tip: Use a gutter width of approximately 
- .25 inches for 2 to 3 columns
- .20 inches for 4 columns. 
- For additional columns, continue decreasing the gutter width.
5. Select **Preview** to view your guides as you adjust the settings.
6. After verifying the layout preview, click **OK**.

>Result<!--?? -->: When this step is completed successfully, purple column guides will appear on the parent page. Use these guides to place text frames, image frames, and background elemennts. For more information, see *Adding Text Frames* and *Adding Image Frames*.

## Apply the Parent Page
1. In the **Pages** panel, select the parent page thumbnail.
2. Drag the parent page thumbnail onto a document page thumbnail.
3. Release the mouse button when a black border appears around the document page thumbnail.
4. Repeat steps 2 and 3 to apply the parent page to the remaining document pages in that section.
