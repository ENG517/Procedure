Learn how to create style templates for your InDesign project using parent pages.

## Prequisites

Before getting started with the parent page, be sure to:
- Assemble the text, images, and other content needed for your project.
- Create a new project in InDesign.
- Configure the settings for your desired page dimensions and number of pages.

## Create a New Parent Page

<!-- We'll get into some copyediting later, but you should avoid burying helpful info within parantheses. Instead, simply use a colon. "...: *Windows* > *Pages*." -->
1. Open the **Pages** panel in the menu bar: **Windows** > **Pages**
2. In the upper right corner of the panel, click the small icon with 4 horizontal bars.   <!-- add image -->
3. Select **New Parent...** from the dropdown menu.
4. Add a prefix letter in the **New Parent** dialog box. The first parent should be "A", the second "B", etc.
5. Add a name for the parent page in the dialog box.
6. Once you verified the page size and orientation, click **OK**
>Note: When you have done this successfully, you will see your newly named parent page appear in the pages menu on the right side of the page.

## Add Column Guides

1. In the **Pages** panel, double-click the newly created parent page to open it in your workspace.
2. Open the **Margins and Columns** dialog box in the menu bar: **Layout** > **Margins and Columns**.
3. In the dialog box, selected the desired margins and number of columns.
4. Select the spacing between the columns, known as **Gutters**.
>Tip: Margins should be at least .5 inches on each side. Recommended gutter size is .25 inches for 2 to 3 columns, and .20 inches for 4 columns. For more columns, continue to decrease gutter size.
5. Check the box marked "Preview" so that you can view your guides on the page as you create them.
6. Once you verified the desired result with the preview, click **OK**.

## Apply the Parent Page
1. Go back to the **Pages** panel and select the parent page at the top of the panel.
2. Click on the parent page thumbnail and drag it over the thumbnail for the desired document page.
3. Apply the parent page by releasing the mouse button when a black rectangle appears on the border of the document page thumbnail.
4. Repeat steps 2 and 3 to apply the parent page layout to the remaining document pages in that section.
